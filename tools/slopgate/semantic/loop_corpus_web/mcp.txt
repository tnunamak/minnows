Model Context Protocol

MCP is an open protocol that standardizes how applications provide context to large language models. Think of MCP like a USB-C port for AI applications: a standardized way to connect AI models to different data sources and tools.

MCP helps you build agents and complex workflows on top of LLMs. It provides a growing list of pre-built integrations that your LLM can directly plug into, the flexibility to switch between LLM providers, and best practices for securing your data within your infrastructure.

Get started with the quickstart guides, or explore the example servers.
