`lpCompare()` in `quicklistCompare()` will call `lpGet()` again, which would be a waste.
The change will result in a boost for all commands that use `quicklistCompre()`, including `linsert`, `lpos` and `lrem`.

BTW, since the comparison of integers requires a call to `string2ll()` each time, perhaps we could convert the `robj` being compared to a number outside the loop, as lpFind does, but this will also lead to reduced readability.
Like following:
```c
    unsigned char *vstr;
    size_t vlen;
    long long lval;
    vstr = TRY_CONVERT_OBJ(argv[3], &vlen, &lval);
    while (listTypeNext(iter,&entry)) {
        if (listTypeEqual(&entry,vstr,vlen,lval) {
            ...
        }
    }
```
