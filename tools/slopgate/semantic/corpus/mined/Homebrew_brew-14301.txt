This PR expands the existing suite of rubocops that enforce the use of `on_system` blocks over `if` statements. Now, the style checks will catch more cases that slipped through before.

Most importantly, this PR adds the ability to check for `if MacOS.version` conditionals in casks. This is the last major step needed before we can switch the cask API loading to JSON files instead of from source.

Big thanks to @bevanjkay and @p-linnane for doing most of the work to get the cask repos switched over.
