# Connector Runtime Migration

## Overview

This document details the migration of the connector runtime to a per-connector sandbox architecture.

## Background

Connectors fetch data from external providers, and the runtime process executes them. Currently, all connectors share a single process, which limits isolation and complicates debugging.

## The Change

The migration moves each connector into its own sandboxed process. This mechanism isolates memory and file system access, preventing one connector's failure from crashing the shared runtime.

## Verification

Unit tests pass for the new sandbox initialization logic. CI reports green status, and code coverage remains at 84%. These results verify the sandbox setup but do not confirm long-term stability under load.

## Summary

The connector runtime now executes each connector in an isolated sandbox, improving fault containment and security.
