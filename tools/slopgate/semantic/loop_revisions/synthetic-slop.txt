# Connector Runtime Migration

## Overview

The connector runtime migration moves execution from a shared process to per-connector sandboxes. This change improves isolation and maintainability for the connector subsystem.

## Background

Connectors fetch data from external providers, and the runtime executes them. Currently, all connectors run within a single shared process.

## The Change

The migration isolates each connector in its own sandbox. This mechanism prevents cross-connector interference and restricts resource access.

Tests pass for the migration suite. CI is green. Coverage remains at 84%.
