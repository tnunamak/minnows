The mail backend tests were opaque and brittle, making maintenance difficult. This refactor improves clarity by replacing manual state tracking with `mock.Mock` in `test_connection_can_be_used_as_contextmanager`. We extracted file handling logic into helper methods within `FileBackendTests` to reduce duplication. The monolithic `test_file_sessions` test was split into focused tests for file creation, reuse, and reopening. Tests now use `EmailMessage` and `backend.send_messages` directly instead of `send_mail`. We replaced boolean assertions with `assertIs` to be more explicit. `test_auth_attempted` now mocks `smtplib.SMTP.login` to verify login behavior. No new functionality was added, and existing coverage remains unchanged.
